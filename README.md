# Slimefun4 精简版 (Slim Version)

基于 [Slimefun4](https://github.com/TheBusyBiscuit/Slimefun4) v4.1.15 的大幅精简版本，只保留最实用的核心功能，适合轻量化服务器使用。

## 精简原则

- **只保留 11 个核心物品/机器 + 完整护身符体系**（普通护身符 + 13 种护身符及其末影版），移除其余数百个物品
- **禁用研究系统** — 所有物品无需解锁即可使用
- **禁用扩展插件** — 不加载 EmeraldEnchants、ExoticGarden 等附加组件
- **保留核心框架** — BlockStorage、指南书、配方系统等基础设施完整保留

## 合成配方

所有物品（除增强型合成台外）均在**增强型合成台**中合成。

### 增强型合成台（多方块结构）

不是普通工作台合成，而是用原版方块搭建：

```
[工作台]     ← 上方
[发射器]     ← 下方
```

右键点击工作台，发射器中放入配方材料即可合成。

## 编译构建

```bash
mvn package -DskipTests
```

编译产物位于 `target/Slimefun v4.1.15.jar`

## 部署

1. 将 JAR 放入服务器的 `plugins/` 目录
2. 确保已安装 [CS-CoreLib](https://github.com/TheBusyBiscuit/CS-CoreLib)
3. 重启服务器
4. 使用 `/sf guide` 获取指南书

## 兼容性

- **服务端**：Bukkit/Spigot 1.12+
- **Java**：1.8+
- **依赖**：CS-CoreLib v1.5.18

## ⚠️ 从原版 Slimefun 更新的注意事项

如果服务器上已有原版 Slimefun 放置的机器方块：

- 旧方块的**数据不会丢失**（BlockStorage 按字符串ID存储）
- 但已注册移除的机器**无法交互**（右键无反应）
- **破坏旧机器方块不会掉落物品**，方块直接消失
- 建议更新前让玩家手动拆除所有粘液科技机器

## 修改说明 (vs 原版 v4.1.15)

### 代码修改

| 文件 | 修改内容 |
|------|----------|
| `SlimefunSetup.java` | **大幅精简**：从原版 100+ 物品注册精简到 11 个核心物品，移除 Grind Stone、Armor Forge、Ore Crusher、Compressor、Jetpacks、Solar Helmet、MultiTool、Soulbound 等非核心物品及其配方、交互逻辑和事件处理。**护身符体系已完整恢复**：全部 13 种护身符 + 普通护身符 + 末影结晶 I/II/III，配方改用原版材料在增强型合成台合成（不恢复魔法结晶/魔法合成台等原版前置链），末影版随本体自动注册 |
| `Talisman.java` | `create()` 放宽末影版创建条件：只需 `ENDER_LUMP_3` 已注册（原版还要求魔法合成台） |
| `EnderTalisman.java` | 末影护身符配方类型由 `MAGIC_WORKBENCH` 改为 `ENHANCED_CRAFTING_TABLE`（在增强型合成台合成） |
| `config.yml` | **新增** `enable-researching: false` — 默认禁用研究系统，所有物品无需解锁即可直接使用 |
